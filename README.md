# Southend Creative Weekend — Web Refresher

Web Refresher – Reflection

Module: CCO5104-20P – Web Development II
University: Bath Spa University

Reflection

During this Web Refresher project, I developed a responsive event website called Southend Creative Weekend using HTML5, CSS3 and JavaScript. I found creating the basic HTML structure straightforward, especially organising the header, navigation menu, sections and footer. Using CSS to change colours, fonts and spacing was also relatively easy.

However, I found responsive design and JavaScript more challenging. I needed to understand how media queries adjust the layout for different screen sizes and how event listeners make buttons interactive. Working with the registration form and switching between Saturday and Sunday schedules helped me understand DOM manipulation.

During Web Development II, I would like to improve my JavaScript skills, particularly DOM manipulation, event handling and debugging, so I can develop more interactive and user-friendly websites independently.

Use of Online Sources / AI

I used OpenAI ChatGPT to assist with the HTML structure, CSS styling, JavaScript functionality and understanding the code. Google Fonts was used for website typography.
